Как подключить мост
  1. Скопируй один или несколько мостов (кнопка 📋).
  2. Tor Browser → Настройки → Подключение → Мосты → «Добавить мост вручную» → вставь строки.
  3. На Android: Tor Browser → ⚙ → Настройки Tor-сети → «Добавить мост вручную».
  4. Если не подключается — возьми другие мосты из списка: часть может быть недоступна.
Источник: igareck/vpn-configs-for-russia. Список подтягивается напрямую из GitHub и обновляется сам, пока страница открыта; кэш хранится в браузере, поэтому вкладка открывается мгновенно. Доступность каждого моста из браузера проверить нельзя — это делает сам Tor при подключении.
